≡Plan

shopgen plan prints a summary; -out writes JSON lines.

↻shopgen run loop

  1. Safety gate: refuse unless partnerDevelopment
  2. Pace to 60s ÷ opm × 1.02 (5/min on dev stores)
  3. orderCreate with backdated processedAt, inventory bypassed, no emails
  4. orderCancel if the plan says cancelled
  5. Save state.json atomically, then next
