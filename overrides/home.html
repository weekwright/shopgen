Why shopgen

A test store that behaves like a real one

An empty dev store makes every report look flat. Hand-made orders all land today and never get refunded. shopgen plans a whole history from a small JSON profile, then creates it safely.

{% include ".icons/material/chart-timeline-variant.svg" %}

Realistic shape

Growth trends, day-of-week and hour-of-day curves, spikes, noise, best sellers and loyal repeat buyers.

{% include ".icons/material/repeat.svg" %}

Reproducible

Same profile and catalog, same orders, every time. A plan is a pure, seeded function of its inputs.

{% include ".icons/material/restart.svg" %}

Survives overnight runs

Paced to Shopify's 5-per-minute dev-store limit. Stop, crash or kill -9 it: resume leaves no gaps and no duplicates.

{% include ".icons/material/shield-check-outline.svg" %}

Dev-store safe

Refuses non-dev stores, checks scopes before writing, never emails anyone and never touches inventory.

{% include ".icons/material/key-chain-variant.svg" %}

Tokens handled

Use a shpat_ token, or let shopgen mint and refresh 24-hour tokens from a Dev Dashboard app.

{% include ".icons/material/broom.svg" %}

Clean up in one command

purge deletes only the orders and customers shopgen tagged, for one run or all of them.

Workflow

Check, preview, create, clean up

  1. Check

    Credentials, dev-store flag, scopes and catalog, without writing anything.

    shopgen doctor

  2. Preview

    See volume, revenue, outcomes and run time for your profile.

    shopgen plan

  3. Create

    Smoke test with a few orders, then backfill the whole history.

    shopgen run --limit 3

  4. Clean up

    Remove everything a run created when you're done.

    shopgen purge --run <id>
