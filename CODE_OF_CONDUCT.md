# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be kind, assume good faith, and keep discussion about the work.

Report unacceptable behavior privately to the maintainers through a [GitHub security advisory](https://github.com/weekwright/shopgen/security/advisories/new) or by contacting a maintainer directly. Reports are handled confidentially.
